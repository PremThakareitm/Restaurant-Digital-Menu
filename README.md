# Restaurant-Digital-Menu

Problem Statement

Restaurants require a digital menu system. This project focuses on designing and
developing a Flutter-based mobile application related to 'Restaurant Digital Menu'.
Students are expected to understand the real-world problem, analyze user requirements,
and design an intuitive mobile interface. The application should demonstrate how mobile
technology can simplify everyday tasks and improve user experience through efficient
design and functionality.

Detailed Feature List

Menu category tabs (starter, main course, dessert), dish cards with image, dish description
section, price display and currency formatting, search dish feature, filter dishes by
category, favorite dish option, item detail page with ingredients list, image gallery for
food items, responsive layout using Row/Column/Grid, navigation between menu
screens, asset image integration, UI animations for menu cards, add-to-order preview
section, restaurant information section.

Expected Outcome

Develop a mobile restaurant menu interface that displays dishes, images, descriptions,
and prices in a clean and user-friendly UI.
